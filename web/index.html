Install Hestia on this PC

Adds Hestia to your Start menu and desktop. No admin rights needed, and you can uninstall it from Windows Settings like any app.

Is local control possible here?

Hestia listens for Sonoff switches announcing local control on this network, then checks it can reach them directly. Nothing is changed on the switch.

Save the switch's key

Each switch encrypts its local commands with its own key. Hestia reads it once, straight from the switch, and stores it encrypted for your Windows account. No eWeLink account is used.

  1. Put the switch in setup mode

    Press and hold the switch's button for about 5 seconds until the blue light blinks fast. Then hold it again for about 5 seconds until the blinking changes pattern. You don't need to open the case.

  2. Join the switch's Wi-Fi from this PC

    Open the Wi-Fi menu and connect to ITEAD-10000… with password 12345678. Windows will say "No internet". That's expected.

  3. Read the key

  4. Reconnect and let the switch return

    Reconnect this PC to the normal Wi-Fi. The switch leaves setup mode by itself after a few minutes or when its power is cycled. If it doesn't come back, add it again in the eWeLink app as usual; the key stays the same.
